# EcoTrack — Smart Waste Reporting System

## Project Overview
EcoTrack is a web-based application that allows users to report waste-related problems in locations such as college campuses and public areas.

## Features
- Submit waste reports with location, waste type, and description.
- Assign a default status of Reported.
- Check application health through a health endpoint.

## Technologies Used
- Python
- Flask
- HTML and CSS
- Git and GitHub

## How to Run the Project
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
